## 从清晰的结构开始

一篇容易阅读的文章，通常先给出问题，再解释过程，最后留下结论。标题帮助读者找到位置，段落帮助读者理解想法。

Markdown 让这些结构保持简单。你可以使用 **粗体强调关键内容**，也可以用 `行内代码` 标记一个命令。

## 留下一段代码

给代码补上一句用途说明，比单独贴出代码更有帮助。

```typescript
const journal = {
  author: "Airglow",
  topics: ["技术", "灵感", "日常"],
};

console.log(`Welcome to ${journal.author}`);
```

## 用表格整理信息

| 内容 | 适合的表达方式 |
| --- | --- |
| 操作步骤 | 有序列表 |
| 方案对比 | 表格 |
| 核心观点 | 简短段落 |
| 可运行片段 | 代码块 |

## 为读者留一点空间

避免一个段落塞进太多内容。把解释写清楚，把参考放在需要的地方，然后读一遍，删去多余的话。
