# 短记

公开页面：https://allenxia814.github.io/notes/ 。顶部导航与手机菜单均有「短记」。

## 在网页中发布

1. 打开 https://allenxia814.github.io/admin/ ，使用你的 GitHub 账号登录。
2. 选择「短记 → 新建短记」，填写简短标题、记录时间和内容。
3. 可添加标签，也可在「配图」中上传多张图片并填写图片说明。正文支持 Markdown。
4. 点击「发布」。后台保存至 GitHub 后会自动构建部署，等待 Actions 完成，刷新短记页面即可看到。

修改或删除：在后台打开对应短记，修改后发布，或使用删除入口。隐藏：开启「隐藏短记」后发布，部署完成时该条短记会从列表、独立页面、搜索与短记 RSS 移除。关闭即可重新展示。公开 GitHub 仓库中的源文件和历史仍可查看，隐藏不适合存放私密信息。

记录时间在页面统一显示北京时间，排序按实际时间从新到旧。编辑器时间选择器使用浏览器本地时区，保存时携带时区；此字段不是定时发布开关。标题用于管理、独立链接页面和搜索；首次发布生成带时间的文件名，之后修改标题仍保留原地址。

每页展示 10 则，自动生成更早记录的分页。点击标题、时间或「查看短记」进入独立页面；点击配图在新窗口查看原图。站内搜索包含已公开短记，列表页不重复进入搜索索引。

独立 RSS：https://allenxia814.github.io/notes/rss.xml 。文章 RSS 保持原有内容。

## 本地文件

在 `src/content/notes/` 新建 Markdown 文件，例如 `2026-10-02-a-moment.md`：

```markdown
---
title: 一次小发现
published: '2026-10-02T20:30:00+08:00'
draft: false
tags:
  - 日常
images: []
---
这里写自己的短记内容。
```

配图字段格式为 `images: [{ image: /images/uploads/photo.webp, alt: 图片说明 }]`；支持站内路径或 HTTPS 图片地址。标签、配图可省略。不要使用 `_` 开头的文件名，这类文件不会发布。此目录目前没有个人记录，首次内容由你发布。
