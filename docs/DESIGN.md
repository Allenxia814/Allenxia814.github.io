# Airglow 星夜杂志

起始页：https://allenxia814.github.io/

文章首页：https://allenxia814.github.io/blog/

## 起始页

打开根网址会先展示星夜欢迎页，点击「进入博客」进入 `/blog/`。导航栏「主页」返回文章首页，点击 Airglow 标识返回起始页。文章分页使用 `/blog/2/` 等地址，文章、短记、友链、后台与 RSS 的原有地址不变。

起始页复用现有夜空素材，展示最新公开文章入口，不读取私人音乐数据。所有入口均为普通链接，无需 JavaScript；星轨动画尊重系统减少动态效果设置。

## 精选文章

在 `/admin/` 中打开文章，开启「首页精选」并发布。首页会把它放在大幅精选卡片中。多篇开启时，选发布日期最新的公开文章；未指定时，展示最新公开文章。隐藏文章不会进入精选。

精选文章不在下面的普通卡片中重复显示，普通文章每页八篇；归档、标签与文章 RSS 仍包含全部公开文章。首页下方显示最近三条公开短记，暂无短记时展示空状态。

## 封面

已有图片保留，套用统一的品牌、分类、星轨和渐变样式。未上传图片的文章使用原生 SVG 与 CSS 的星夜图案，技术、灵感、日常分类有细微差异，不需要额外准备图片。文章详情也使用相同封面样式。

在后台「封面」字段上传图片可以替换背景。封面装饰不进入图片画廊；上传的真实封面可以在文章详情中点击放大。

## 图片查看

文章正文与真实封面、短记正文与配图支持 PhotoSwipe 灯箱。每篇文章、每则短记各自形成一组，图片加载后自动取得真实尺寸。点击图片原地打开，支持左右箭头或方向键切换、缩放、手机滑动、Esc 关闭，并展示图片说明。

图片链接若指向其他网页，仍按原链接跳转。图片尚未加载时保留原图入口，避免用猜测尺寸打开灯箱。浏览器关闭 JavaScript 后，短记配图仍有原图链接。切换页面时销毁旧画廊并重新初始化，尊重系统减少动态效果设置。
